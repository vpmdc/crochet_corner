# Welcome to the Crochet Assistant

Version: 1.0.0

CrochetCorner is an AI Agent powered assistant that helps find, learn and execute crochet patterns and techniques. Whether you're a beginner or a seasoned crocheter, this tool is designed to support your creative journey.

The full documentation for CrochetCorner can be found at [CrochetCorner](https://azure-samples.github.io/contoso-sales-azure-openai-assistants-api/).
